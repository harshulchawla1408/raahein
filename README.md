# 🌍 Raahein - Your Smart Travel Companion

**Raahein** is an intelligent travel planning platform that crafts personalized travel experiences based on your **budget**, **duration**, and **preferences**. Whether you're planning a solo trip, a group vacation, or a college tour, Raahein helps you discover the best destinations, manage bookings, and connect with like-minded travelers — all in one place.

---

## ✨ Features

- 🔍 **AI-Powered Suggestions**  
  Get destination recommendations tailored to your inputs like budget, number of days, interests, and travel style.

- 💸 **Cost Estimation Engine**  
  Real-time estimation of total trip cost including travel, stay, and activities.

- 📅 **Plan & Book**  
  Browse destinations, make bookings, and reserve spots for attractions in advance.

- 🧑‍🤝‍🧑 **Social Travel**  
  Connect with other solo or group travelers with similar interests or timelines.

- 🏫 **College Trip Planner**  
  Organize college tours, group trips, and bulk bookings with ease.

---

## 🏗️ Tech Stack

### 🖥 Frontend
- **Next.js** (React)
- **Tailwind CSS**
- **Framer Motion** (for smooth animations)

### 🌐 Backend
- **Node.js** with **Express.js**
- **MongoDB** for database
- **Firebase** for authentication
- **Gemini API** for AI travel suggestions
- **Swagger UI** for API documentation

### ⚙️ Dev Tools
- Postman / Thunder Client
- Git & GitHub

### Frontend
